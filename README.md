# GradePilot — GPA Calculator

A browser-based **semester GPA and cumulative GPA calculator**, built with **HTML, CSS and JavaScript** as an educational front-end demo.

![GPA calculator screenshot](screenshots/gpa-preview.png)

## Features
- Add, edit and remove courses, credit hours and grades.
- Calculate semester GPA and projected cumulative GPA (CGPA).
- Configure grade-point values in the built-in grade-scale editor.
- Save working data in the browser using local storage.
- Export course results as a CSV file and print a report.
- Responsive design for smaller screens.

## Built with
HTML5, CSS3, vanilla JavaScript; no server or third-party API is required.

## Run locally
1. Download this repository.
2. Open `index.html` in your browser.
3. Enter course credits and grades. To compute CGPA, add your previous GPA and completed credits.

## Live demo on GitHub Pages
Go to **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save** after uploading the project.

## Important note
The grade-point table is **customizable** and may not match the official grading rules at your university by default. Confirm the university's actual grading system before using results for academic planning.
